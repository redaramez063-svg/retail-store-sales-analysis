## 📌 Project Overview
A data analysis project focused on identifying sales performance trends for a retail store. 
The analysis revealed a significant year-over-year sales decline and provided actionable 
insights to support data-driven business decisions.

## 🎯 Objectives
- Analyze historical sales data to detect performance trends
- Identify the root cause of sales decline in a specific year
- Build an interactive dashboard for business stakeholders

## 🛠️ Tools & Technologies
| Tool | Purpose |
|------|---------|
| Power BI | Data Visualization & Dashboard |
| Figma | Dashboard UI Design & Prototyping |

## 📊 Key Findings
- Identified a significant **year-over-year sales decline** in a specific period
- Pinpointed underperforming product categories driving the drop
- Provided recommendations to recover lost revenue
